## 2. Defense Mechanisms

### 2.1 ML-Based Circuit Breaker

```
Location: backend_api/api/trades/views.py (lines 98-190)
```

**Logic Flow:**
1. Trade request received
2. ML Risk Model evaluates (`predict_trade_risk()`)
3. Score > 0.85 → Trade REJECTED
4. Score > 0.90 → User AUTO-BANNED

**Evidence:**
```python

    u.role = User.Role.BLOCKED
    u.is_active = False
    SecurityLog.objects.create(...)
```

### 2.2 Role-Based Access Control (RBAC)

**Groups Created:**
- `SuperAdmins` - Full system access
- `Whales` - Advanced analytics
- `MarketMakers` - Liquidity management

**Permissions Assigned:**
- `ban_user` → SuperAdmins only
- `view_advanced_analytics` → Whales
- `add/change/delete_market` → SuperAdmins
